Right now I'm freelancing and working on a few side-projects of my own.

**CGI (2021–2024).** Two client projects running in parallel: a micro-frontend platform for Volkswagen Group in Germany (React, Redux, module federation) and a React Native app for Compass Group's catering operations in France.

**Before 2020** I was in Brazil, working on loyalty apps for British American Tobacco and retail partners, mobile apps used by the Rio de Janeiro state police and the São Paulo Public Prosecutor's office, and a geolocation app that connected people with lawyers.
